# Plain writing

The rules are in `references/rules.md`. Read the file and apply it to all text you write. If the session already contains these rules, do not read the file again.

## Rewrite or review text

Use this procedure when the user asks you to rewrite, tighten or check existing text.

1. Read the whole text and its context: the audience, the sibling pages and the project voice guide if there is one. Choose the register as `references/rules.md` describes.
2. Make a diagnosis before you rewrite. List the problems that you found, with short quotes and counts, for example "14 em dashes, 3 '-ing' tags, 'In conclusion' wrap-up". Also list claims that have no evidence.
3. Rewrite. Keep the structure and the meaning unless the user asks for a different result. Keep strong lines that already follow the rules.
4. Check the result against each rule in `references/rules.md`.
5. Report briefly: what you changed, each claim that you made weaker or stronger, and the questions that the user must answer.

For a review only, do steps 1 and 2 and suggest fixes. Do not rewrite.
